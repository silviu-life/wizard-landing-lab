# wizard-landing-lab

Un laborator de pagini de landing pentru Claude Code. Completezi un brief într-un dashboard local, agenții construiesc mai multe pagini în runde, tu le notezi (Îmi place / Poate / Nu, cu note și exemple), iar runda următoare pornește din notele tale până alegi pagina câștigătoare, pe care o primești ca HTML.

## Instalare

```
/plugin marketplace add silviu-life/wizard-landing-lab
/plugin install wizard-landing-lab@wizard-landing-lab
```

Apoi `/wizard-landing-lab:landing-lab-install`: verifică ce îți lipsește (uv, Python, Chromium), îți explică fiecare piesă și o instalează doar dacă spui „da”.

## Folosire

`/wizard-landing-lab:landing-lab` și spui pentru ce produs vrei pagina. Se deschide dashboard-ul în browser; restul se întâmplă acolo.
